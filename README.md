# CWSP-WOLF

Source for cwspwolf.com, the NC State Campus Writing and Speaking Program site for WOLF (Written and Oral Literacy Facilitation) and the C²TC Communication Teaching Certificate. Maintained by Kirsti Cole (kkcole2@ncsu.edu).

The site publishes from the `main` branch through GitHub Pages. WOLF pages sit at the root, C²TC pages in `c2tc/`, and downloadable handouts in `c2tc/docs/`.
